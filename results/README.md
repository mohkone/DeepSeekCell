# Manuscript Result Bundle

This directory contains the curated result bundle cited by the BMC Bioinformatics manuscript. These files are tracked so that the manuscript's "Availability of data and materials" statement points to concrete outputs in the GitHub repository.

The tracked bundle includes:

- final benchmark tables and dataset summaries;
- paired statistical tests and confidence-quality outputs;
- refinement-behavior and correction-efficiency summaries;
- native CellTypist baseline metrics;
- GPT-5 and cross-model selector summaries;
- selected external-validation and biological-validation outputs;
- submission-hardening and reproducibility audit artifacts.

Large or local-only artifacts remain intentionally untracked, including raw external resources, `benchmark_cache/`, `benchmark_debug/`, exploratory smoke-test outputs, API logs, and large bootstrap distributions. The full Cell Ontology OBO file and ScType database should be obtained from their upstream sources according to their licenses.
